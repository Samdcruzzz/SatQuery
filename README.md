# 🛰️ SatQuery: AI-Powered Satellite Image Analysis

**An intelligent vision-language model system for real-time satellite image interpretation**

## 🚀 What is SatQuery?

SatQuery is a **proof-of-concept AI system** that brings vision-language models to satellite imagery analysis. Imagine asking questions about what you see in satellite images—and getting intelligent, context-aware answers instantly.

**Current Demo:** The system demonstrates how advanced AI can unlock insights from satellite data by combining computer vision and natural language processing.

**Future Vision:** We're building towards a comprehensive platform that enables:
- 🌍 Real-time Earth observation intelligence
- 🔍 Automated disaster response analysis
- 📊 Environmental monitoring at scale
- 🎯 Precision agriculture insights
- 🛰️ Urban planning & development tracking

---

## ✨ Current Capabilities (Demo)

This is a **working demo** showcasing core functionality:

- **Satellite Image Processing** - Load and preprocess satellite imagery
- **Vision-Language Integration** - Analyze images using AI models
- **Interactive Querying** - Ask questions about satellite data
- **Dataset Management** - Organize and manage satellite datasets
- **Web Interface** - User-friendly demo application

## 🚀 Quick Start

### Prerequisites
- Python 3.8+
- `pip` package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/ThanuShree99/SatQuery.git
cd SatQuery

# Install dependencies
pip install -r requirements.txt

# Run the API
python api/index.py

# Access the web interface
# Open http://localhost:5000 in your browser
```
